# Case Bot (Telegram)

Кейсы с подарками, Сапёр, Апгрейдер, инвентарь, пополнение через Telegram Stars, вывод по заявкам, бонус, рефералы, админ-команды.

## Деплой на Render
1. Загрузите эти файлы в репозиторий GitHub.
2. Render → New → Blueprint → выберите репозиторий (подхватит `render.yaml`, создаст базу и сервис).
3. В переменных сервиса укажите `BOT_TOKEN` (от @BotFather) и `ADMIN_IDS` (ваш Telegram ID, несколько через запятую).
4. Deploy. Free-сервис засыпает без трафика — бот сам пингует свой URL каждые 10 минут.

## Админ
`/admin`, `/stats`, `/pending`, `/give id сумма`, `/take id сумма`, `/broadcast текст`.
Заявки на вывод приходят админам с кнопками «Выполнено / Отклонить» (при отклонении возврат автоматический).

## Настройки (необязательные переменные)
`MIN_DEPOSIT`, `MAX_DEPOSIT`, `MIN_WITHDRAW`, `MIN_DEPOSIT_TO_WITHDRAW`, `REF_PERCENT`, `MINES_RTP`, `UP_RTP`.
Игры: Сапёр, Ракета, Курочка, Монетка, Кости, Колесо, **Плинко** (RTP 85%), **Башня** (RTP 80%).
Отдача кейса задаётся параметром `rtp` в `_mk(...)` (например `rtp=0.80`); без него берётся `CASE_RTP`.
Новые кейсы: 🎀 Сюрприз (80%), 💝 Подарок мечты (85%), 🌸 Сакура (80%).
Кейсы и подарки меняются в `bot.py` (словари `ITEMS` и `CASES`).

## Provably Fair (`fair.py`)
Исход = HMAC-SHA256(server_seed, `client_seed:nonce:блок`). Игрок видит `sha256(server_seed)` заранее; в Профиле → «Честность» можно сменить client seed, раскрыть старый server seed и пересчитать свои ставки в браузере. Работает для кейсов (мини-апп), Сапёра, Курочки, Башни, Монетки, Костей, Колеса, Плинко, Апгрейда, Крафта. Ракета: хеш seed раунда виден до старта, seed раскрывается после взрыва (`client="crash"`, nonce = № раунда). Смена seed блокируется, пока идёт Сапёр/Курочка/Башня. Игры Сапёр/Апгрейд внутри Telegram-бота (`bot.py`) пока на обычном `secrets`.

## Neon: настройки скорости
Переменные (необязательные): `DB_KEEPALIVE` (сек, по умолчанию 240; 0 = выкл) — пока есть активные игроки, бот раз в N секунд «будит» базу, чтобы Neon не засыпал; `DB_ACTIVE_MIN` (30) — сколько минут после последнего запроса считать игроков активными; `DB_POOL_MIN` / `DB_POOL_MAX` (2 / 10); `DB_NO_PS=1` — только если используете pgbouncer без prepared statements.
Для скорости создайте проект Neon в том же регионе, что и сервис на Render (например Frankfurt ↔ Frankfurt), и используйте строку подключения с `-pooler`.

## Бесплатный кейс
Раз в 24 часа. Дроп: 0 ⭐ — 80%, 1 ⭐ — 15%, 5 ⭐ — 4%, 10 ⭐ — 1%. Шансы задаются в `FREE_CASE_DROPS` (`bot.py`), на клиенте не показываются; в мини-аппе бесплатный кейс — обычная карточка с призами без процентов.

## Обязательные подписки
`SUB_CHANNELS="@channel1,@channel2"` — два канала (бот должен быть админом в обоих). Канал без username: `-1001234567890|https://t.me/+инвайт`. Пусто = выключено.
- `/start`: подписки показываются только новым игрокам и один раз (флаг `users.gate_passed`); у уже существующих игроков они не спрашиваются.
- Бесплатный кейс: перед открытием проверяется подписка на оба канала; если уже подписан — открывается сразу.

### BotoHub
`BOTOHUB_TOKEN` — токен со страницы https://botohub.me/integration. Если задан, спонсоров выдаёт BotoHub (`POST /get-tasks`, заголовок `Auth`), а `SUB_CHANNELS` не используется. Если BotoHub недоступен — игрока не блокируем.

### Задания от BotoHub (+0.5 ⭐ за задание)
Раздел «📋 Задания» есть в боте (кнопка в меню) и в мини-аппе (только Профиль). Кнопка видна всегда; задания подгружаются из BotoHub, когда задан `BOTOHUB_TOKEN`.
Бот берёт задания у BotoHub (`/get-tasks`) и показывает игроку. Когда игрок выполнил задание, оно пропадает из выдачи BotoHub — бот засчитывает его и начисляет `TASK_REWARD` ⭐ (по умолчанию `0.5`).
Баланс целый, поэтому дробная часть копится в `users.task_cents`, а каждая накопленная целая ⭐ уходит на баланс (2 задания = 1 ⭐). За одну и ту же ссылку платим один раз (таблица `hub_tasks`).

## Профиль (мини-апп)
Кастомизация: ник, аватар-эмодзи, цвет, титул (колонки `users.prof_*`, роут `profile/set`, значения из белого списка). Ежедневный бонус в профиле мини-аппа убран.

## Свои задания
`LOCAL_TASKS` в `bot.py`: канал @buvego — подписка, проверяется ботом (бот должен быть админом канала), +0.5 ⭐ один раз. Работает без BotoHub.
При `/start` (новым игрокам) и перед бесплатным кейсом проверяется подписка на @tgk_oskegcase (`SUB_CHANNELS`, по умолчанию `@tgk_oskegcase`; бот должен быть админом канала).
